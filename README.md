# MediTrack - Milestone 2

Integrated Patient Care Management System for patient registration, appointments, consultations and prescriptions.

## What This Project Includes

- Patient registration with unique Patient IDs such as `PAT001`, `PAT002` and `PAT003`.
- Patient profile management for blood group, allergies, existing diseases, medical history, medications, emergency contact and insurance details.
- Database-style storage using browser `localStorage`.
- Appointment scheduling with doctor, date and time slot selection.
- Slot management that blocks a doctor's booked time slot for the selected date.
- Patient record retrieval for registration details, profile details and appointment history.
- Consultation management for symptoms, diagnosis and treatment notes.
- Prescription generation with medicine, dosage and duration.
- A SQL schema in `database.sql` showing the milestone database design.

## How To Run

Open `index.html` in a browser.

No installation is required because the project uses plain HTML, CSS and JavaScript.

## Modules Covered

1. Patient Registration
2. Patient Profile Management
3. Database Design
4. Appointment Scheduling
5. Patient and Appointment Information Retrieval
6. Consultation Management
7. Prescription Management

## Notes

Data is retained in the browser using localStorage. Load Demo provides sample records for all modules.
